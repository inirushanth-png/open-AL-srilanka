# Open A/L Sri Lanka
An open-source data pipeline and archive of GCE A/L resources to democratize education in Sri Lanka.

###  Mission
Democratizing advanced-level education resources in Sri Lanka by breaking data silos and providing open, equal access to high-quality academic materials for every student, regardless of their socio-economic background.

### Architecture & Goals
**Phase 1 (Now):** Open-sourcing the structured dataset of GCE A/L past papers, pilot exams, and marking schemes.

### 📂 How to Contribute
We welcome students, teachers, and developers to contribute missing papers, official answer sheets, or software tools to expand this pipeline. Check `CONTRIBUTING.md` for guidelines.
